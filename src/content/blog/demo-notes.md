This is a **sample post** showing how common text elements look on the blog: headings, lists, tables, quotes and code blocks.

## Folder structure [toc]

Each topic gets its own folder with short Markdown files:

```text
notes/
├── linux/
│   ├── file-permissions.md
│   └── systemd.md
├── windows/
│   └── services.md
└── networking/
    └── osi-model.md
```

## Kinds of notes [toc]

| Kind      | When                      | Length      |
|-----------|---------------------------|-------------|
| Cheat sheet | quick reminder          | 1 screen    |
| Concept   | new theory                | 1–2 screens |
| Log       | after each study session  | a few lines |

> **Tip:** a short note written right away beats a long one you never write.

### Note template
